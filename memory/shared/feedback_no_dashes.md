Never use em-dashes, en-dashes, or `--` constructions as sentence connectors or parenthetical setters. Always use `:` or `,` based on what fits sentence flow. Markdown bullet markers using `- ` should be replaced with numbered lists (`1.`, `2.`, `3.`) or comma-separated prose where the email or document body will render those markers literally.

Compound hyphens in standard English words (full-time, twenty-minute, walk-through, by-pass) are allowed. The user uses these themselves. The rule is about dashes as stylistic punctuation, not hyphens as part of compound spelling.

**Why:** User stated strongly during email drafting for the VA reasonable accommodation case: "alway never use - or -- in any of this shit always : or ,"

**How to apply:** Apply to all prose: emails, documents, READMEs, any user-facing text. Keep markdown structural elements (table separators `|---|`, horizontal rules `---`) since those are required syntax, not prose.
