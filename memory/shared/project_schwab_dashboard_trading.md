Gotchas found 2026-10-12: Windows os.replace raises PermissionError when a reader holds the file (use scripts/file_lock.replace_file); pyarrow read_table on a file under a `timeframe=1_min` folder adds a clashing hive partition column (use ParquetFile); Lightweight Charts pans on its own mousedown (mouse events, no pointer events), so drawing code stops mousedown and click in the capture phase on #chart; Python 3.9 f-strings cannot nest same-type quotes or hold backslashes; `python -I -m pkg` cannot find repo packages (-I drops cwd); never pass `'''` through a bash heredoc into Python, write the script with the Write tool. Real thinkorswim export layout: BOM, "Watchlist 'Name'", blank, the name alone, header "Symbol,...", records whose cells can span lines in quotes, futures as /ES[H25]. Schwab's 1m depth for nearly 24-hour futures is about 29 sessions (40k bar cap); data/schwab/fill_runs/confirmed.json marks days Schwab no longer has.
4. Do not route panel orders through `TraderAPI.place_order` or `SchwabClient.execute_order` (duplicate-order risk).
