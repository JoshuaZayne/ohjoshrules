**THE GOTCHA THAT CAUSED IT, worth remembering for any signed PDF:** DocuSign **flattens completed signatures into page images** and leaves the AcroForm signature fields empty. So checking form fields, `page.widgets()`, or extracted text reports "unsigned" on a fully executed document. **Only rasterizing the page and looking at it can answer "is this signed?"** — use `scripts/render_pdf.py` (added 2026-08-11, 3.5x). Note the agreement DOES have a 128k-char text layer, so text search still works for locating which page to render, just never for signatures.
