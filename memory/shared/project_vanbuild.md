`~/repos/VanBuild` (git-init'd 2026-05-30) holds the off-grid campervan electrical spec: README + 4 docs under `docs/`.

Core design: mini split = 9,000 BTU **120V** unit (~600 W real-world, run off inverter; cheaper than 12V DC units) at 9 h/day. Load = ~7.6 kWh/day (6 kWh A/C + 1.6 kWh house). 5-day battery-only autonomy => ~40 kWh nominal at **48V** (8x EG4 LL-S 5.12 kWh ≈ $11.5k, ~680 lb - flagged as payload reality; trimmed 4-battery / 2-3 day build ≈ $11k total). Inverter = Victron MultiPlus 48/3000 (also the shore/EV charger). Solar = 5x 400W (SanTan used panels cheapest). Alternator charge = 12V->48V DC-DC (FOVAL 800W stock / Sterling 1500W needs upgraded alt). EV-port charge = J1772->NEMA adapter + control module into inverter AC-in (J1772 has no neutral - caveat). Purple Twin XL: 5 dealer links.

User explicitly OK'd a system "more powerful than 48V residential" as long as batteries+inverter match - 48V residential class is the right answer at this scale. **Hard constraint: NO 12V anything** - all-48V bank, all loads 120V AC off the inverter (no 12V appliances, no 48V->12V converter); the only 12V allowed is the van's factory alternator, and even that is replaced in the recommended path by a 48V alternator + Wakespeed WS500. No 12V DC mini split (uses 120V AC unit instead).

`VanBuild_Builds.xlsx` (built by `build_xlsx.py`, openpyxl) has a sheet per build type: Overview, Full 5-Day Build (~$17.4k, 8x EG4, ~680 lb), Trimmed 2-3 Day Build (~$10.7k, 4x EG4, ~340 lb), Phased Plan, Product Options (5 each w/ links). Docs: README + docs/01-05.
